# Decisions Log

History only. Each line records one decision, why we made it, and what it changed. **The current state of the project is in [spec.md](spec.md)**; you don't need this file to understand what we're building. Use it to answer "why did we do it this way?"

Entries are appended, never edited. If a decision is reversed, add a new entry that says which one it replaces.

"Spike" refers to the [calibration test](../spikes/reverb_itd/RESULTS.md). "Proposal" is `report/main_proposal.tex`.
